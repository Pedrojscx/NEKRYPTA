# Atribuição

## Base original

O NEKRYPTA é um fork do **Shale**, shell de desktop para Hyprland criado por **TurcanS** e distribuído sob a licença **MIT**. A base original e os avisos de copyright continuam sendo reconhecidos.

Repositório upstream: <https://github.com/TurcanS/shale>

## Modificações deste fork

Este repositório, **Pedrojscx/NEKRYPTA**, contém modificações, integrações e documentação próprias sobre a base do Shale, incluindo o Modo de Segurança Mullvad, auditoria de exposição local e localização da interface.

## Licença

Este repositório é privado e não traz arquivo `LICENSE`. A base original foi publicada sob a licença MIT, que exige manter o aviso de copyright e o texto da licença em cópias e redistribuições. O texto original continua no repositório upstream e no histórico deste repositório (commits anteriores a esta remoção). Antes de tornar o repositório público ou distribuí-lo, restaure o `LICENSE` original.
